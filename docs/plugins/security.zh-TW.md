# 安全檢查清單

請把每個插件都視為不受信任程式。只宣告實際需要的 host、secret 和 API 權限，並以必要的最小資料量處理使用者資訊。

- 不要把密鑰放在原始碼、`plugin.json`、log、通知、錯誤訊息或範例套件。請讓使用者在插件面板儲存密鑰，再用 `api.secrets.get` 讀取。密鑰以作業系統安全儲存機制加密；一般 settings 不含密鑰值。
- 不要記錄 Authorization header、API token、使用者私密資訊。Log 會留在本機診斷面板。
- 網路只能經 `api.net.fetch`。不可用 Web API 直連；每次 redirect（最多 3 次）都重新檢查 HTTPS、授權 host 與公開 DNS 位址。`requestHost` 必須由使用者同意，且可在面板撤銷。
- 面板只能在 `permissions.links` 宣告精確 HTTPS 網域，並於目前這次可信任使用者操作後透過 `links.openExternal` 開啟。面板不會取得 `shell`、導覽或任意 IPC 能力。
- 插件網路請求不會送出或儲存 Cookie。需要登入的 API 請使用 `authorization` header 與已宣告的密鑰。`settings.onChange` 不會包含密鑰值；需要時請在 callback 中呼叫 `api.secrets.get`。
- 每一跳連線前都會檢查 DNS；HTTPS-only、443 port 與 TLS 憑證驗證可降低 DNS rebinding 時間差風險，但無法完全消除，仍列為已知殘餘風險。
- 插件不能讀取其他插件的儲存、密鑰或執行狀態。使用者可停用插件、撤銷動態 host 或移除插件；移除會刪除密鑰。
- Manifest 權限更新會要求重新同意。開發者模式預設關閉；開啟期間只載入你明確選取的資料夾，檔案變更會重新驗證。不要執行來源不明的開發資料夾。

App 的沙箱不是插件程式碼可信的保證。處理插件錯誤時，提供錯誤碼即可，不要暴露路徑或憑證。

## 發布前檢查

- [ ] `plugin.json` 中的每個權限與貢獻點都有被程式碼使用，沒用到的就移除。
- [ ] 主機使用確切名稱（除非每個子網域都需要，否則不用萬用字元）；只需要開啟網頁時，使用 `links.hosts` 而非 `network.hosts`。
- [ ] 原始碼、manifest、紀錄、通知與錯誤訊息中沒有憑證、權杖或個人路徑。
- [ ] 密鑰在使用當下才用 `api.secrets.get` 讀取，絕不複製到儲存、設定、紀錄或面板訊息。
- [ ] 來自網路的資料一律視為不可信：放進面板 HTML 前先跳脫（用 `textContent`，不要用 `innerHTML`），也絕不執行。
- [ ] 通知文字與 `link` 值來自已知來源；連結指向你已宣告的主機。
- [ ] 輪詢遵守限制（每分鐘網路、每 10 分鐘通知、16 個排程），遇到 `rate_limited` 與 `Retry-After` 會退避。
- [ ] 套件只包含你要發布的檔案，且最終的壓縮檔就是你簽章並計算雜湊的那一份。
- [ ] 發布說明列出新增的權限。更新若新增網路、連結或密鑰權限，或更換簽章金鑰，使用者需要額外確認。
- [ ] 私鑰不在儲存庫、套件或目錄中。

## 面板主題

主題只有資料。主程式以封閉語法解析每個顏色，自行重新輸出 `rgb(R G B / A)`、字型名稱與尺寸；渲染端在 `style.setProperty` 前再以白名單檢查名稱與值，任何插件字串、`url()`、`var()` 或遠端網址都不會進入 CSS。字型（`.woff2`，檢查檔頭）只會在面板渲染程序中由 Chromium 的字型清理器解析。圖片在任何解碼之前先檢查檔頭（尺寸、像素數、動畫、方向），且只透過每次啟動都不同的 `agent-pets://panel-theme/<token>` 提供，插件頁面與 Worker 都無法存取。使用者匯入的背景由原生對話框選擇、只讀取一次並在記憶體中驗證，存為 `userData/panel-theme-images/<插件>/<sha256>`（0o700／0o600），插件看不到，清除或移除插件時會刪除。沒有保護區域：權限與風險提示、安裝確認、插件內容框、確認對話框與寵物視窗都跟著主題；主機在接受主題前先證明每個文字色在它可能出現的每個表面上都清楚（包含疊在全黑與全白桌面上的寵物泡泡與狀態列）、焦點環維持可見，且危險／成功／警告／資訊色維持色相、彼此之間及與強調色保持距離。版面、文字標籤、風險徽章文字與「按住才允許」由主機程式碼決定。至少 0.50 的圖片遮罩讓圖片裡的「按鈕」只看起來像背景。

**讀取主題。** `theme.get()`、`theme.onDidChange()` 與面板頁上的 `--ap-*` 屬性不需要權限：內容只有使用者已經看得到的顏色、圓角、字族名稱與字級倍率，每個插件拿到的都相同，不含插件或主題 id、字型別名、圖片、路徑或使用者背景。數值由宿主產生，preload 以 `style.setProperty` 寫入前會再檢查（固定名稱，`rgb()`／`px`／字族／數字格式）。面板透過只允許設定面板 main frame 的單向頻道把淺色／深色模式告訴主程序；變更最多每 100 ms 一次送到 Worker 與開啟中的面板頁。插件可以比對顏色推測目前使用的主題；這屬於顯示資訊，已接受此風險。
