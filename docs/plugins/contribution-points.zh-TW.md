# 畫面貢獻點

插件可加入通知與反應、提供設定與淨化後的 Agent 狀態，也可在設定面板加入隔離的自訂頁面。

| 項目 | 使用者看到的內容 | 同時出現時的順序與操作 |
|---|---|---|
| `feed` | 寵物泡泡，含插件來源、標題、內文、可選圖示與連結；通知也保留在插件通知中心。 | 泡泡仲裁：權限請求／提示 → presentation say → Agent toast → normal 插件通知 → activity → low 插件通知。normal 預設，low 只在 activity 之後顯示。使用者可關閉、點擊連結、標記已讀或清除。 |
| `reaction` | 寵物做出 `happy`、`curious`、`thinking`、`surprised` 或 `encouraging` 反應。 | 排在一般 Agent / 插件互動佇列中；勿擾時拒絕。使用者可停用插件或總開關。 |
| `settings` | 插件面板內由 manifest schema 產生的設定表單；密鑰欄位以密碼欄呈現且不回顯。 | 表單由使用者儲存；背景程式可讀取設定並訂閱變更，不能以 Host API 改寫。 |
| `agentStatus` | 不新增泡泡；允許插件讀取目前寵物狀態並收到狀態變更。 | 每隻寵物的快速變更合併 1 秒；欄位只含 `petId`、`name`、`agentFamily`、`previousState`、`visibleState`、`dnd`、`at`。 |
| `panelView` | 設定面板中的 HTML 頁面；頁面外有宿主繪製的插件名稱、圖示、「插件內容」標記與關閉按鈕。 | 頁面使用獨立沙箱 `WebContentsView`，只能與同一插件的 Worker 交換有界限的 JSON 訊息；不能蓋住宿主外框或存取 App renderer。詳見[自訂面板頁](panel-view.zh-TW.md)。 |
| `commands` | 插件面板「指令」清單中的使用者操作按鈕。 | 使用者只能執行該插件已宣告的指令。插件透過 `commands.onInvoke` 收到指令 id；不能自行觸發，也不能操作其他插件的指令。 |
| `tray` | 內建 Tray 項目之後、「結束」之前的插件子選單；每個符合條件的插件各有一層子選單。 | 只列出已啟用插件與已宣告指令；全部最多顯示 30 個插件指令。標籤是純文字，最多 32 字，超過會截斷。使用者選取後走與面板相同的指令 callback。 |
| `badge` | 寵物狀態列旁的小型膠囊；游標停留或鍵盤聚焦時顯示插件名稱與徽章文字。 | 寵物可見時最多顯示 2 個插件徽章，其餘合併為 `+N`。Mini、Edge 或寵物隱藏時不顯示；插件停用、移除或崩潰時清除。 |
| `skins` | 可選擇的插件寵物外觀，標示「來自插件：<插件名稱>」。 | 使用者可套用，但不能單獨重新命名或刪除。停用／移除插件後寵物回到預設外觀，進度資料保留。只有外觀的插件不建立 Worker。 |
| `eventSource` | 在獨立插件狀態清單顯示「來自插件：<插件名稱>」的唯讀狀態列。 | 插件只能送出 session id 與允許的狀態；不能替換或混入內建 Agent 狀態、觸發 Permission、XP、成就、History、quota 或通知。狀態只存在記憶體，停用、移除、崩潰、重新載入或逾時後清除。 |

使用者可在面板關閉插件、全域停用、靜音單一插件、調整通知速率及目標寵物。DND、寵物不可見或速率／佇列限制會讓通知進通知中心，而非泡泡。安裝同意畫面會以一般文字列出指令、Tray、徽章與外觀；更新新增貢獻時需重新同意。
