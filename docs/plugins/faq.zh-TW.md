# 常見問題與疑難排解

**插件已安裝，但什麼事都沒發生。**
新安裝的插件預設停用。請在「已安裝」開啟它，並確認插件功能已在全域啟用（關閉時會有橫幅提醒）。隱藏的 Plugin Host 只在至少有一個插件啟用時才會執行，且預設同時最多執行 10 個插件（可在「進階」調整）。接著開啟**詳情 → 診斷**。

**`activate` 有執行，但沒看到氣泡。**
勿擾開啟、寵物被隱藏、插件被靜音或觸發速率限制（預設每個插件每 10 分鐘 5 則）時，不會顯示氣泡；該則通知仍會出現在**通知**分頁。在隱藏或勿擾期間產生的項目事後不會補播。詳見[通知行為](notifications.zh-TW.md)。

**為什麼我的套件被拒絕？**
請檢查[打包規則](packaging-and-versioning.zh-TW.md)：只允許 `.js`、`.json`、`.png`、`.webp`、`.html`、`.css`；總大小最多 5 MB、最多 64 個檔案（含外觀的套件最多 25 MB）；`plugin.json` 與宣告的 `entry` 必須在 ZIP 根目錄；不得有符號連結、重複路徑、`..` 路徑，或面板目錄以外的 HTML。`unsupported_api_version` 代表 `apiVersion` 不是 `"1"`。

**為什麼更新時又要再次同意？**
新增任何權限或貢獻點都需要重新同意，新增高風險項目（網路、連結、密鑰，或簽章金鑰變更／被移除）還需要勾選確認。請盡量讓各版本的權限保持穩定。詳見[權限與同意畫面](permissions.zh-TW.md)。

**插件可以呼叫 HTTP API、IP 位址或 localhost 嗎？**
不行。`api.net.fetch` 只接受 HTTPS、公開 DNS 名稱、443 連接埠，且主機必須由你宣告或經使用者核准。固定主機用 `network.hosts`；由使用者決定的主機則使用 `network.userGranted` 搭配 `api.net.requestHost`。

**API 權杖該放在哪裡？**
在 `permissions.secrets` 宣告，於 `settings` 加入 `format: "secret"` 欄位，再用 `api.secrets.get(key)` 讀取。使用者在插件設定中輸入；它存放在系統安全儲存區，不會出現在設定快照，也不會傳給 `settings.onChange` 回呼。任何插件第一次儲存密鑰時，App 會顯示一次性的提示（macOS 可能會詢問鑰匙圈存取）。

**插件可以修改自己的設定嗎？**
不行。Worker 只能讀取設定並訂閱變更，只有使用者能編輯。插件自己的狀態請放在 `api.storage`。

**插件可以執行 shell 指令、讀取檔案或使用 Node.js 模組嗎？**
不行，詳見[沙箱](sandbox.zh-TW.md)。需要本機工具的工作請做成獨立的 App，必要時再透過 HTTPS 提供結果。

**我的面板頁是空白或顯示錯誤。**
確認 `panelView.entry` 指向套件內的 `.html` 檔，且所有資源都是套件內的檔案（頁面唯一能載入的外部網址是 `agent-pets://plugin/_shared/tokens.css`）。使用**重新載入面板**、查看**診斷**，並記得頁面內 `fetch` 與 `WebSocket` 會被封鎖，請改用 `api.net.fetch`。載入超過 5 秒時可選擇取消。

**面板開啟的大小不對。**
`preferredSize` 仍會被驗證，但不再改變視窗大小：控制面板所有畫面共用一個使用者可調整的大小（最小 360×420，最大到螢幕可用範圍），請讓你的頁面能自適應。

**我的排程不再執行。**
回傳 Promise 的回呼在完成前會擋住下一次觸發（Host 會跳過重疊的執行）、每個插件最多 16 個排程，且有效間隔不會低於 manifest 的 `minIntervalSec` 或使用者設定的最小值（預設 60 秒）。Worker 連續崩潰三次會停用插件。

**如何移除插件的所有資料？**
使用**移除插件…**並勾選**同時刪除設定與資料**。不勾選時，設定、密鑰與權限會保留，方便重新安裝。

**紀錄在哪裡？**
在插件的**診斷**分頁，以及 `logs/main.log` 中頻道為 `plugin:<id>` 與 `plugin-host` 的紀錄。詳見[測試與除錯](debugging.zh-TW.md)。

**`apiVersion` 會變嗎？**
目前只有 `"1"`。尚未公布跨主版本的過渡期；不支援的 API 版本會顯示為不相容。
