# UX 全面翻修階段報告（PR #25）

| 類別 | 項目 |
|---|---|
| 稽核問題 | PET 20、SP 18、PL 18、ON 15、PM 15、GR 16、DS 19、RL 15，全部完成 |

| 使用者回饋與實機驗證 | UI-01〜09、CR-02 |

## 主要成果

- **插件體驗**：
  - 已啟用的插件直接出現在主畫面的分頁，不必再進設定翻好幾層。
  - 設定裡另有獨立的「插件」群組，負責安裝、權限與更新。
  - 安裝確認改為依風險分組，需要時必須明確勾選確認。
- **面板**：
  - 設定分成 5 個群組，頂端可以搜尋。
  - 標題列是 ⋮ 選單、設定、關閉；面板可縮放到全螢幕，所有畫面共用同一個尺寸。
  - 支援淺色／深色主題，寵物外觀可以和面板分開設定。
- **寵物**：
  - 氣泡移到寵物上方，結果提示可讀。
  - 動畫狀態交叉淡入淡出，拖曳不會拖出螢幕，Mini 和 Edge 模式改善。
  - 新增右鍵選單；寵物可以用鍵盤操作，也支援螢幕閱讀器。
- **權限**：
  - 倒數與過期回饋、經遮蔽的參數、風險分級，以及只對非高風險請求開放的快捷鍵。
  - 多個請求排成佇列，並說明哪些工具只能回到工具本身確認。
- **成長與用量**：
  - XP、升級和成就都有慶祝效果。
  - 快取 token 不再灌水（history schema v6）。
  - 額度錯誤有回饋；本機 log 掃描改為非同步。
- **穩定性**：
  - 全域錯誤兜底，重複出錯時會詢問是否重新啟動。
  - renderer 崩潰時自動重載。
  - 可以匯出診斷資訊；連接埠失效時會顯示提示。
  - session 快照、計時器與結束流程都整理過。
- **效能**：
  - 事件 p99 延遲從 13.09 ms 降到 7.08 ms。
  - v6 遷移處理 5 萬筆事件從 3.6 秒降到 0.6 秒。
  - 主 bundle 從 252.7 KB 降到 149 KB。
- **CI**：
  - 純文件變更不跑 CI。
  - release 的驗證與建置平行執行，macOS 雙架構也拆開平行建置。
  - 新增 lint、覆蓋率門檻、bundle 大小、對比度與設計 token 的嚴格檢查。

## 驗證

- `vue-tsc --noEmit`：通過。
- `pnpm test:coverage`：869 通過、0 失敗，達覆蓋率門檻。
- `vite build`、`pnpm lint`、`check:bundle`、`check:bundle-size`、`check:contrast`、`check:design:strict`：全部通過。
- **安全**：
  - 依 phase-gates 審查新增的 IPC、權限、本機伺服器、檔案系統與 redaction。
  - `pnpm audit --prod` 沒有已知漏洞；diff 的 secret 掃描沒有命中。
  - 詳見 [security-review.md](../ux-overhaul/security-review.md) 的「修正狀態」。
- **實機（macOS）**：用 `scripts/e2e-isolated-electron.mjs` 隔離環境（暫時 HOME／userData、假 safeStorage）透過 CDP 截圖，確認了：
  - 首次啟動精靈
  - 主畫面
  - 設定麵包屑
  - ⋮ 選單
  - 淺色主題
  - 伺服器離線橫幅
  - 面板縮放限制（最小 360×420，最大到工作區）
- **實機驗證找到並修正的整合退化（CR-02）**：
  - 面板視窗被重複建立後消失。
  - 插件分頁讀不到徽章。
  - 首次啟動的精靈不會自動打開。

## 殘餘風險

- **插件分頁內容**：嵌入的面板頁和徽章沒有在執行中的 App 上驗證，因為安裝插件需要原生檔案對話框，自動化碰不到。
- **Windows**：全部未實機驗證，清單在 [windows-todo.md](../ux-overhaul/windows-todo.md)。
- **macOS 開機啟動**：在打包、未簽章、從「應用程式」外執行的情境未驗證，留待 PR 5 的簽章與公證一起處理。
- **偶發不穩的測試**：`presentation-stdio` 在機器高負載時偶爾逾時，單獨跑會通過。
- **刻意跳過的子任務**：記錄在各問題的工作記錄 nextSteps，後續依序處理：PR 2 體驗功能 → PR 3 插件生態 → PR 4 資料與效能 → PR 5 跨平台與打包。
